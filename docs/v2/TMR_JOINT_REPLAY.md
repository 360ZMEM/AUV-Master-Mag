# 实测 TMR--ArUco 数据的 v2 FWHM 适用性审计

输入是现有 45 Hz 联合实验产生的 777 个同步磁场--位姿点，时长
41.65 s。工具只读加载 `aligned_timeseries.npz` 和对应的
`fit_summary.json`，不修改原始数据或旧实验结果。

运行：

```bash
cd AUV-Master-Mag
PYTHONPATH=src python3 tools/v2_replay_tmr_joint.py
```

工具以复 I/Q 联合拟合得到的导线轴为基准，将 TMR 位置分解为：

- 沿导线坐标；
- 法平面内的主要横切坐标；
- 法平面内的次要坐标。

主要横切坐标经平滑后被拆成单调扫描腿。每条扫描腿同时接受生产 v2
FWHM 估计器和两个轨迹门：沿缆位移/横切跨度不超过 0.25，次要方向
位移/横切跨度不超过 0.20。只有双侧半高交点、剖面模型和轨迹门全部
通过时才允许输出距离。

结果：

| 指标 | 数值 |
|---|---:|
| 对齐样本 | 777 |
| 候选单调扫描腿 | 9 |
| 轨迹几何通过 | 4 |
| 双侧 FWHM 有效 | 0 |
| 允许发布距离/埋深 | 0 |
| 全记录沿缆跨度 | 0.2133 m |
| 主要横切跨度 | 0.6459 m |
| 法平面次要方向跨度 | 0.2642 m |

所有候选腿均缺少至少一侧半高交点；部分腿还存在明显非平面运动或沿缆
漂移。因此，这组数据可以证明 v2 会拒绝不完整的真实信号剖面，但不能
标定 FWHM 场形系数或验证绝对埋深。原实验是手持三维轨迹，没有受控的
平面双侧横切，也没有同步海床高度真值。将其强行变成埋深会形成伪真值。

新结果写入 `results/v2/tmr_joint_replay/`，包括逐腿 CSV、JSON 摘要、图和
本地报告。完成实测精度验证仍需要受控双侧横切、导线/海缆位置真值、
同步 TMR 位姿以及同步高度或海床基准。
