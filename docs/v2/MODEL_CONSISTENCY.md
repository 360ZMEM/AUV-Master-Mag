# FWHM 场模型一致性审计

实验入口：`tools/v2_fwhm_model_consistency.py`。它在同一 case1 直线电缆位置，针对 2、3、4、6、8 m 垂直间距，比较三种无噪横截面。

| 场模型 | 平均 shape factor `z/W` | 范围/标准差 | 解释 |
|---|---:|---:|---|
| 论文偶极包络 `1/(x²+z²)` | 0.500000 | 固定 | 满足论文 `W=2z` |
| v2 物理单直导线 | 0.289102 | std 0.000188 | 接近理论 `1/(2sqrt(3))=0.288675` |
| v1 legacy 线段公式 | 0.472036 | 0.433130–0.494563 | 随距离变化；2 m 时用 0.5 会高估深度约 15.4% |

量纲审计显示，v1 `math_utils.finite_wire_field_nT` 的核心项为 `cross/denominator`，量纲为 `1/m²`。v2 对照公式增加 `|r1|+|r2|` 因子，恢复 `1/m`，并已通过长导线极限 `mu0 I/(2 pi r)` 单元测试。v2 没有修改 v1 模型，以免改变历史结果。

这组结果说明 FWHM 宽度本身可以统一提取，但从宽度换算深度时必须记录模型来源和 shape factor。当前建议：

- 论文远场偶极解析实验使用 0.5；
- 真正的解析单直导线 Biot–Savart 数据使用 0.288675；
- 当前 PVS `perception_engine.py` 与 v1 一样采用线段中点电流元近似，使用经场景标定的约 0.472，并报告模型来源；不能把它当作解析单直导线；
- legacy v1/PVS 仿真不使用一个固定系数跨全部距离宣称无参精度；
- 实测多芯铠装海缆的系数必须由可溯源横切数据验证。

原始结果位于 `results/v2/fwhm_model_consistency/`。
