本次审阅服务于“在工程可接受条件下，海缆巡检输入输出可靠、系统持续运作，并能用于真实部署”的完整目标；不以单个磁估计、软件单测或零推力输出替代该目标。当前可固定的论文贡献是主动空间观测、横向/身份/埋深许可分离和有界任务工作流；真实任务是否能够连续运行，按同次来源时序与运动证据判断。

## 当前版本与已有结果的关系

当前 ROS 巡检包标准整包测试 **101/101** 通过；本次检查的巡检、决策、控制、桥和 common 顶层模块 **62/62** 与安装文件同 SHA-256，其中桥包包含三个保留的历史备份模块。common 的历史备份目录不属于安装模块，未计为版本差异。磁算法当前源码回归 **88/88** 通过。两套测试均无失败，ROS 标准测试结果另确认无错误或跳过。

旧候选快照核对发现 6 个源码/启动/配置/夹具文件已演进，旧实验数据哈希未变。这是版本演进，不是将旧数据作废；但图 61 的旧版完整航迹不能直接充当当前源码的整任务验收。[当前审阅归档](../../results/v2/inspection_candidate_review_20260928/review.json)将当前源码、安装匹配、测试日志与旧快照差异单独固定，明确不是完整构建包或现场放行包。原快照和历史图像保持不变。

ROS 整包测试使用系统 Python 3.10.12，磁算法源测试使用当前 shell 的 Conda Python 3.10.19。两项验证功能行为；磁回归含多次 2300 点横切，期间有只读调用栈观察且最初与 ROS 测试并行，其整体耗时不能替代部署平台的实时周期验证。解释器、文件系统、线程限制和导入路径随归档记录。

对 `origin/main`（`6e4632a296feef6c706588b06dc57bfe0899e967`）的有限范围内容核对忽略行末空白/换行差异，保留原始补丁供查阅：现有控制器、仲裁器、自治守卫、接口消息和生产 VxWorks 文件未见内容差异。既有共享代码的内容差异集中在 5 个 Python 文件：任务消息增可选 ID、磁跟踪增展示字段/模式格式、解耦仿真增解析场及演示流程、感知节点支持正常退出、共享桥增默认关闭的 IMU 包时间检查。另有独立 `inspection_v2_candidate` C 候选/主机测试、IMV1 sidecar 和测试文件，未混为生产固件变更。此项只核对清单所列路径，不证明全仓或硬件等价；v2 专用 PID/执行桥仍按自身合同验收。

## 从审阅到下一次有效验证
