# 声磁电缆跟踪方法图集

本目录维护 5 张声磁电缆跟踪方法图。图内只保留结构、状态、几何和数据流信息；
图名、适用边界与证据说明由引用文档的图注承担。

## 资产与再生

- 可编辑源：`fig_*.drawio`
- Markdown 预览：`fig_*.png`
- 矢量出版物：`fig_*.svg`
- PDF 出版物：`fig_*.pdf`
- 内嵌可编辑 PNG：`fig_*.drawio.png`
- 统一生成器：`generate_drawio_method_figures.py`

生成器采用统一的中文论文样式：节点正文不小于 19 pt，泳道标题 21 pt，主路径与反馈路径
分别使用实线和虚线；输入、过程、判断、准入、状态与数据产物使用不同几何形状。

## 图 1 五层架构与每帧闭环

![声磁电缆跟踪五层架构与每帧闭环](fig_arch_onion.png)

**建议图注：** 声磁电缆跟踪系统的五层架构与每帧约 20 Hz 闭环：左侧区分传感器输入、
环境与物理、感知与融合、控制与决策、可视化与编排，右侧给出从采样到载体推进的执行顺序。

左侧表达静态职责边界，右侧表达动态时序。分层不表示每个节点只依赖相邻层，实际数据契约
以部署接口为准。

## 图 2 声磁感知流水线

![声磁感知流水线](fig_perception_pipeline.png)

**建议图注：** 高频磁采样经滤波、矢量特征和峰值检测形成峰值序列；声呐锚点参与中心线
定向，随后生成局部路径、横偏、埋深、重捕候选与统一置信度状态。

图中 200 Hz 与约 20 Hz 是磁仓当前实现口径。主论文采用
`AUV-Master-Project/docs/thesis/figures/architecture/cable_acoustic_magnetic_perception_pipeline`
的学术化重绘，不直接复制本图。

## 图 3 电缆跟踪子任务五态 FSM

![电缆跟踪子任务五态 FSM](fig_mission_fsm.png)

**建议图注：** 电缆跟踪子任务由搜索、锁定、跟踪、有界重捕和应急上浮五态组成；正常主轨、
重捕支轨与不可逆安全终态分离，短时失锁时保留已收敛中心线。

本图只描述磁仓内部的电缆跟踪模式，不替代主论文中由行为树统筹的整艇任务生命周期。

## 图 4 受控横切构造局部可观测性

![受控横切构造局部可观测性](fig_zigzag_probe.png)

**建议图注：** AUV 受控横切电缆产生穿缆峰值观测，加权 PCA 拟合局部中心线，声呐锚点
消除纯磁方向的 180° 歧义；横切角和扫描间距共同决定局部观测密度。

本图是磁仓原始可编辑几何源。主论文采用
`AUV-Master-Project/docs/thesis/figures/architecture/cable_active_crossing_observability`
的双面板学术化重绘，并额外表达峰值定位与 FWHM 垂直距离反演。

## 图 5 行为树、模式 FSM 与子机制

![行为树、模式 FSM 与控制感知子机制](fig_statemachine_hierarchy.png)

**建议图注：** 行为树负责安全抢占和任务授权，电缆跟踪模式 FSM 管理搜索至应急的阶段，
控制与感知子机制分别执行受限横切和提供局部路径、候选区域、埋深与置信度。

该层级避免把磁仓内部模式 FSM 表述为整艇唯一调度源，与主论文“行为树全局调度、状态机管理
阶段、局部机制执行动作”的职责边界一致。
